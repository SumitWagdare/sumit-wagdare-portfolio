# Sumit Hansraj Wagdare - Portfolio 🚀

Welcome to the source code for my interactive, single-page portfolio website! This project leverages modern web technologies to create an immersive, Apple-inspired liquid glass experience.

## ✨ Features

- **Liquid Glass Aesthetics**: Premium frosted glass components (Glassmorphism), dynamic radial background gradients, and an "Obsidian" dark theme.
- **Scroll-Triggered Animations**: Smooth stagger reveals, parallax image effects, and a horizontal pin scrolling section powered by **GSAP**.
- **Inertia Scrolling**: Silky smooth vertical scrolling physics utilizing **Lenis**.
- **Custom Interactions**: A magnetic liquid cursor that inverts colors and scales up organically when hovering over interactable elements.
- **Fluid Responsiveness**: Scalable Grid and Flexbox "Bento-Box" components that look stunning from ultra-wide 4K monitors down to mobile displays.

## 🛠️ Technology Stack
- **HTML5 & Vanilla CSS3**: Utilizing modern CSS variables, Grid, Flexbox, and complex `backdrop-filter` calculations.
- **Vanilla JavaScript (ES6+)**: Custom scripting for handling fluid cursor dynamics and coordinating GSAP timelines.
- **GSAP (GreenSock)**: Industry-standard animation engine used for professional-grade scroll interactions.
- **Vite**: Ultra-fast build tool for rapid development, instantaneous Hot Module Replacement, and highly optimized production bundles.

## 🚀 Getting Started

### Prerequisites
Ensure you have **Node.js** and **npm** installed on your system.

### Installation

1. **Install dependencies:**
    ```bash
    npm install
    ```

2. **Start the development server:**
    ```bash
    npm run dev
    ```
    Navigate to the localhost URL provided in your terminal (usually `http://localhost:5173`) to view the site live!

3. **Build for production:**
    ```bash
    npm run build
    ```
    This generates highly optimized, minified static files located in the `dist/` directory, ready to be deployed to platforms like Vercel, Netlify, or GitHub Pages.
