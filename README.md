# Sumit Portfolio Project (v3)

This folder contains the portfolio website and sample media.

## Structure
- index.html — main portfolio page (copied from your HTML)
- images/ — placeholder images (cup samples, portrait, project images, hero background)
- videos/ — placeholder video (replace with real mp4 files)
- css/, js/ — empty folders for custom assets

## How to use
1. Open `index.html` in a browser to preview.
2. Replace images in the `images/` folder with your real photos. Keep the same filenames or update `index.html`.
3. Place videos in the `videos/` folder and reference them from `index.html` if needed.
4. Customize styles by adding files into `css/` and scripts into `js/`.

## Notes
- Placeholder images are simple colored images with labels (generated automatically).
- The placeholder `videos/sample.mp4` is a tiny placeholder — replace with a real video file before use.
